Confluence como Diário Técnico: organização documental da transição de carreira

Configurei o Confluence para apoiar meu projeto de estudo e transição de carreira, criando páginas para os principais tópicos técnicos e gerenciais da jornada. A intenção é manter um registro organizado dos estudos, decisões, dúvidas, evidências e aprendizados, sem depender apenas de anotações soltas.

Nas páginas principais, configurei uma macro para exibir os links das páginas filhas, facilitando a navegação entre temas e a evolução cronológica da documentação. Também criei um template de espaço chamado Diário Técnico, voltado ao registro periódico da prática, e um template global chamado História de Usuário Global, para padronizar descrições, objetivos e critérios de aceitação.

Embora seja uma configuração inicial, esse uso do Confluence reforça uma competência importante para funções de requisitos, análise de sistemas, suporte e gestão técnico-operacional: transformar estudo em documentação rastreável. A ferramenta passa a funcionar como base de conhecimento, conectando planejamento, execução no Jira, projetos publicados, código no GitHub e evolução profissional.

O template global História de Usuário Global também está disponível para consulta e reutilização: acessar o template no Confluence.
