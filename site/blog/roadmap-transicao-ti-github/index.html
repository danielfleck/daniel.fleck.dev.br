Roadmap de transição no GitHub: do branch dev ao merge na main

Repositório público para organizar a transição técnico-gerencial com documentação, links profissionais, política de dados, templates e evidências do plano de estudos.

GitHubVersionamentoRoadmapPortfólio

Criei o repositório público roadmap-transicao-ti para concentrar a governança da minha transição técnico-gerencial: documentação, links profissionais, política de dados, templates e evidências visuais do plano de estudos.

Para evitar alterações diretas na linha principal do projeto, criei uma branch dev e trabalhei nela. Nessa branch, iniciei os arquivos estruturantes do repositório, incluindo README.md, .gitignore e LICENSE, além de ajustar a documentação por meio de pequenos commits, mais fáceis de revisar e entender.

Antes de levar as alterações para a branch principal, ajustei o histórico com rebase, reduzindo ruído e evitando poluir a main com uma sequência desorganizada de commits intermediários. Depois disso, realizei o merge na branch main, consolidando uma entrega inicial limpa, rastreável e adequada para exposição pública.

Mesmo sendo um projeto pessoal de estudo, tratei o repositório como um artefato profissional: branch de desenvolvimento, commits pequenos, higiene de histórico, arquivo de licença, regras de versionamento e documentação voltada à leitura por recrutadores.
