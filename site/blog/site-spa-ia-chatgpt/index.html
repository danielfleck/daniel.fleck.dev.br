Objetivo do projeto

Criei o daniel.fleck.dev.br para reunir, em uma única presença digital, meu currículo, portfólio, estudos de caso, registros de aprendizado e evidências da atualização profissional em tecnologia.

O site foi estruturado como uma Single Page Application — SPA, construída com HTML, CSS e JavaScript. A navegação entre as seções ocorre na própria página, sem recarregamento completo, mantendo acesso ao painel, plano de estudos, portfólio, ferramentas, blog e consulta de artigos por tags.

Desenvolvimento com apoio do ChatGPT

O ChatGPT foi utilizado como ferramenta de apoio na geração inicial e na evolução do código-fonte, na construção da interface e na revisão dos textos. O processo foi iterativo: cada alteração foi especificada, testada, analisada e corrigida antes de ser incorporada à versão seguinte.

O uso da IA não se limitou à solicitação de uma página pronta. Foi necessário transformar necessidades em instruções objetivas, identificar respostas inadequadas, preservar funcionalidades existentes, corrigir problemas de navegação, ajustar a responsividade e impedir alterações desnecessárias no código.

Funcionalidades e decisões implementadas

  • Navegação SPA entre as seções do site, com rolagem suave e preservação do contexto.
  • Blog técnico com lista de posts, carregamento dinâmico e visualização do artigo principal.
  • Portfólio integrado aos estudos de caso publicados no blog.
  • Nuvem de tags com filtragem dos artigos por assunto.
  • Layout responsivo para computadores e dispositivos móveis.
  • Referência a imagens e documentos externos sem incorporação indevida em base64.
  • Revisão e melhoria dos textos com apoio de IA, preservando a fidelidade da trajetória profissional.

Versionamento e publicação

O código-fonte é gerenciado com Git e mantido em um repositório público no GitHub. Isso permite registrar a evolução do projeto, revisar alterações e manter uma evidência verificável do trabalho realizado.

A primeira publicação do projeto utilizou integração entre GitHub e Vercel. Posteriormente, a hospedagem foi migrada para a KingHost, mantendo o GitHub como repositório oficial, o domínio daniel.fleck.dev.br administrado no Registro.br e o DNS ajustado para a nova infraestrutura. A migração tratou da infraestrutura de publicação. Em paralelo, a formalização de privacidade, Termos de Uso, LGPD, Marco Civil e governança de dados foi conduzida como uma frente própria do projeto.

Competências demonstradas

  • Definição e refinamento progressivo de requisitos para uma aplicação web.
  • Desenvolvimento e manutenção de HTML, CSS e JavaScript.
  • Uso crítico de IA generativa no ciclo de desenvolvimento.
  • Revisão, teste e correção de código produzido com apoio de IA.
  • Versionamento de código com Git e publicação no GitHub.
  • Experiência com deploy integrado por GitHub/Vercel e migração da hospedagem para KingHost, com DNS, HTTPS, acessos administrativos e integração de publicação.
  • Registro de domínio e configuração de DNS.
  • Documentação e apresentação pública de um projeto real.

Resultado

O resultado é um site funcional, publicado em domínio próprio e mantido em repositório público. Além de apresentar minha trajetória, o projeto constitui uma evidência atual de desenvolvimento web, gestão de código, uso responsável de IA e operação do fluxo completo entre criação, versionamento, deploy e configuração de domínio.
