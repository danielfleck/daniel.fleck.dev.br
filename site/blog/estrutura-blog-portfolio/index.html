BlogPortfólioCarreiraEvidências

Este espaço será usado para registrar estudos, decisões técnicas, projetos concluídos e evidências públicas da transição para dados, SQL, indicadores, automação, requisitos e sistemas.

A seção Portfólio exibirá apenas entregas já construídas e publicadas. Cada item poderá apontar para uma página específica do projeto, para o código no GitHub e para um artigo explicando a construção.

O objetivo é registrar evolução real, sem simular experiência ou publicar projetos ainda não executados.

Fluxo de publicação

  • Construir o projeto.
  • Publicar o código no GitHub.
  • Publicar o resultado em uma página própria quando fizer sentido.
  • Escrever um artigo curto explicando problema, solução, tecnologias e aprendizado.
  • Adicionar o item na seção Portfólio.
