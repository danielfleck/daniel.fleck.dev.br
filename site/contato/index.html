Antes de enviar

Envie apenas o necessário para o assunto. Não envie senhas, tokens, dados bancários, documentos de identidade ou dados pessoais sensíveis sem necessidade.

O serviço de e-mail é prestado pela KingHost/LWSA. A infraestrutura do provedor pode tratar dados técnicos de autenticação, transporte e entrega. O responsável pelo site trata os dados que efetivamente chegam à caixa postal para responder e adotar as providências cabíveis.

Mensagens comuns são eliminadas quando deixam de ser necessárias, observados os critérios do Aviso de Privacidade.
