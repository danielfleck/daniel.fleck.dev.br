daniel.fleck.dev.br: site estático multipágina com apoio de IA

Evolução do site pessoal: de uma SPA inicial para uma arquitetura estática multipágina, com URLs próprias para blog, portfólio, erros, tags e documentos legais.

HTMLCSSJavaScriptIA GenerativaGitGitHubKingHostDNSHTTPSSite EstáticoSEOPython

Descrição

O projeto foi inicialmente construído como SPA em HTML, CSS e JavaScript. Em agosto de 2026, a arquitetura foi reorganizada para páginas HTML estáticas independentes, preservando Git/GitHub, KingHost, domínio no Registro.br e HTTPS. A nova estrutura melhora navegação, indexação, manutenção e rastreabilidade, com geração local de índices, tags e sitemap por scripts Python executados apenas no ambiente de desenvolvimento.
