Migração de hospedagem: Vercel → KingHost com GitHub, DNS, SSH, FTP e deploy

Migração técnica do site para a KingHost, preservando o GitHub como fonte do código e separando infraestrutura da frente própria de governança jurídica e de dados.

KingHostGitHubGitSSHFTPDNSRegistro.brWebhookSegurançaInfraestrutura

Descrição

O trabalho envolveu Registro.br e DNS, preparação inicial do diretório remoto via SSH, integração GitHub/KingHost, validação de webhook, revisão e redução de permissões OAuth e proteção das contas administrativas. O FTP administrativo permanece desativado por padrão; a publicação posterior ocorre pelo mecanismo gerenciado de integração com Git da hospedagem. A construção de Termos de Uso, Política de Privacidade, LGPD, Marco Civil e governança de logs foi documentada em um item próprio do portfólio.
