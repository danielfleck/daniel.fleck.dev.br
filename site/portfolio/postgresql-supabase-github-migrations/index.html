Laboratório PostgreSQL: GitHub, Supabase e migrations versionadas

Estrutura criada para estudar SQL e PostgreSQL em um fluxo controlado, com repositório Git, projeto Supabase, conexão pelo pgAdmin 4 e evolução do banco por migrations.

PostgreSQLSupabaseMigrationsGitGitHubSQLpgAdmin 4

Descrição

O projeto registra a criação do ambiente desde o repositório e o banco remoto até a integração entre GitHub e Supabase. Foram configurados comandos auxiliares no package.json, criada uma migration para o schema transicao e outra para uma tabela de exemplo, com verificações pelo dashboard, SQL, pgAdmin 4 e histórico local e remoto das migrations. A IA foi usada como apoio, mas os comandos, erros, correções e resultados foram conferidos em cada etapa.
