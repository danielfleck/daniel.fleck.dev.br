Ferramentas e método

Ferramentas usadas na atualização profissional

Uso prático de ferramentas para planejamento, documentação, versionamento e execução.

Jira Cloud: execução do plano

O Jira Cloud está sendo usado de forma prática para organizar o plano de atualização e retorno ao mercado de tecnologia.

  • Épicos para grandes blocos de estudo.
  • Tarefas com descrição, objetivo e critérios de aceitação.
  • Bloqueios e dependências para reduzir ansiedade de escopo.
  • Filtros e categorias para acompanhar cronologia e prioridade.
  • Uso consciente: ferramenta corporativa real, aplicada a um projeto pessoal.

Confluence: documentação e base de conhecimento

O Confluence é tratado como base de conhecimento, não como prova de domínio técnico avançado.

  • Registro de decisões, conceitos, erros e aprendizados.
  • Páginas por tema somente quando houver estudo real.
  • Documentação de requisitos, critérios de aceitação e processos.
  • Backup periódico para evitar dependência de uma única plataforma.

GitHub: evidência pública

O GitHub será usado para publicar apenas código, consultas, documentação e experimentos realmente produzidos.

  • README claro em cada repositório.
  • Dados fictícios ou públicos.
  • Commits progressivos e descrição dos aprendizados.
  • Sem listar tecnologia como competência antes de haver prática mínima demonstrável.

Dados e SQL: trilha de atualização

A trilha de dados começa por SQL, modelagem e indicadores, atualizando uma base técnica anterior sem superestimar o domínio atual.

  • Consultas SQL e modelagem relacional.
  • Indicadores e dicionário de métricas.
  • Relatórios simples com planilhas e dados fictícios.
  • Ferramentas específicas serão citadas somente após estudo e projeto publicado.

Site pessoal e currículo

O site pessoal deve apresentar o retorno e a atualização profissional de forma madura e objetiva.

  • Currículo em /curriculo.html.
  • Itens de portfólio apenas quando houver projeto construído.
  • Artigos curtos de estudo e decisões técnicas.
  • Narrativa profissional sem exagerar senioridade atual.
