# Segurança

Esta seção documenta controles técnicos aplicados ao site.

## Tópicos previstos

- minimização de exposição;
- separação entre fontes e raiz pública;
- CSP;
- ausência de analytics/pixels próprios;
- proteção de credenciais;
- procedimentos técnicos relacionados a logs e incidentes.

!!! warning
    Não registre segredos, tokens, chaves, senhas, cookies de sessão ou outros dados sensíveis nesta documentação.
