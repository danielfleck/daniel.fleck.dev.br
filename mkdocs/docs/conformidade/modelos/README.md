## Regra crítica

Nunca preencha aqui dados reais. Ao usar um modelo:

1. copie para diretório privado fora do Git público;
2. dê um identificador de caso;
3. preencha somente o necessário;
4. proteja acesso;
5. aplique retenção/descarte.
