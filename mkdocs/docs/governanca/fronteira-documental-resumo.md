# Resumo — Fronteira Jira × Confluence × MkDocs

A regra oficial é:

- **se descreve o produto ou sua implementação → MkDocs**;
- **se descreve trabalho → Jira**;
- **se descreve contexto, estratégia, raciocínio ou decisão → Confluence**.

Exemplo KingHost:

- “por que a KingHost foi escolhida” → Confluence;
- “migrar o site para KingHost” → Jira;
- “como DNS, deploy e acessos ficaram configurados” → MkDocs.

O GitHub mantém código, histórico e as fontes do MkDocs. O Roadmap GitHub deixou de ser fonte oficial do trabalho e permanece apenas como registro histórico quando necessário.
