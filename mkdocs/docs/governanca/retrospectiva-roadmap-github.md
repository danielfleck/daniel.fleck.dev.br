# Retrospectiva — Roadmap GitHub como etapa histórica

## Contexto

O repositório `roadmap-transicao-ti` foi criado como índice público da transição e inicialmente concentrou documentação, links, política de dados, templates e evidências.

## Valor da etapa

O projeto ajudou a consolidar práticas de Git, branches, commits pequenos, rebase, merge controlado e organização documental.

## Mudança de modelo

Com a maturidade do projeto, o Roadmap GitHub deixou de ser a fonte de trabalho. O modelo atual é:

- Jira → trabalho e execução;
- Confluence → estratégia, contexto, decisões e retrospectivas;
- MkDocs do respectivo produto → implementação técnica;
- GitHub → código e histórico.

O repositório pode permanecer como evidência histórica, mas não deve competir com Jira como backlog oficial.


## Preservação documental

Este texto completo é preservado no MkDocs/Git. A página correspondente no Confluence deve conter apenas um resumo contextual e um link para esta versão completa.
