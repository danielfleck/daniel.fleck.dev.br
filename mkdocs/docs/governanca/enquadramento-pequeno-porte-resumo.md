# Resumo — Enquadramento como agente de tratamento de pequeno porte

A governança mantém uma memória específica para verificar a aplicabilidade do tratamento diferenciado previsto pela Resolução CD/ANPD nº 2/2022.

A análise considera a situação do responsável, escala e natureza dos tratamentos, critérios de alto risco, hipóteses que afastam benefícios regulatórios e existência de canal para titulares.

A conclusão não é tratada como permanente: deve ser revista se o site passar a usar autenticação, banco de usuários, tratamento em larga escala, dados sensíveis, monitoramento sistemático, tecnologias de maior risco ou outra mudança material.

Este resumo não substitui a análise completa do caso concreto.
